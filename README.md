# Function Plotter - Web 函数绘制器

一个现代化的 Web 端函数绘制器，支持多函数绘制、隐式方程、求导等功能。

## 🚀 功能特性

### 核心功能
- **多函数绘制**: 支持同时绘制多个函数，每个函数使用不同颜色
- **实时渲染**: 输入函数表达式后实时绘制曲线
- **交互式操作**: 
  - 鼠标拖动平移视图
  - 滚轮缩放
  - 点击特殊点钉选坐标

### 高级功能
- **隐式方程**: 支持 `x^2+y^2=1`、`y^2=x` 等圆锥曲线
- **求导运算**: 支持数值求导，`(sin(x))'` 计算导数
- **特殊点检测**: 
  - 零点、极值点
  - 函数间交点
  - 隐式曲线与坐标轴交点

### 输入支持
- **数学函数**: sin, cos, tan, ln, log, sqrt, abs 等
- **数学常数**: pi, e, tau, inf
- **运算符**: ^ (幂), ! (阶乘), ' (求导)
- **隐式变量**: y (用于隐式方程)

## 🛠️ 使用方法

### 启动服务
```bash
cd GLM
python3 -m http.server 8766
```
然后在浏览器访问: `http://localhost:8766/index.html`

### 基本操作
1. **添加函数**: 点击 "＋ 添加函数" 按钮
2. **输入表达式**: 在文本框中输入函数表达式
3. **查看结果**: 实时查看函数曲线和特殊点

### 示例表达式
```javascript
// 基本函数
sin(x)
x^2 - 3
ln(x)
1/x

// 隐式方程
x^2 + y^2 = 1
y^2 = x
x^2/4 + y^2/9 = 1

// 求导
(sin(x))'
(x^2)'
```

## 🎨 用户界面

### 工具栏功能
- **＋ 添加函数**: 添加新的函数行
- **⟲ 重置**: 重置视图到默认范围
- **＋镜**: 放大视图
- **－镜**: 缩小视图

### 特殊点标记
- **零点**: 函数与x轴交点
- **极值点**: 函数的极大值/极小值
- **交点**: 函数间的交点
- **钉选**: 点击特殊点可钉选坐标信息

## 🔧 技术栈

- **前端**: HTML5, CSS3, JavaScript (ES6+)
- **渲染**: Canvas 2D API
- **数学**: 自定义表达式解析器和数值计算
- **部署**: Python HTTP Server

## 📝 开发说明

### 核心组件

#### Plotter 类 (`app.js`)
- 坐标变换和视图管理
- 网格和坐标轴绘制
- 函数曲线渲染
- 特殊点计算和显示

#### 表达式解析器 (`expr.js`)
- 词法分析器和语法分析器
- 支持数学函数和运算符
- 错误处理和纠错机制

#### 数学输入系统
- 支持 `^` 上标输入
- 智能括号匹配
- 符号自动转换 (ln→自然对数, pi→π等)

### 错误处理
表达式解析提供清晰的错误提示：
- 缺少括号: `(未闭合`
- 语法错误: `需要 OPERATOR，但得到 +`
- 多余输入: `多余的输入：+`
